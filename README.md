# Bash Scripts

This repo holds a collection of useful scripts and guides for installing various softwares. These favor Distrobox for containerization, which is a heavier install that installing to bare metal, however it allows for multiple versions as well as the same scripts working regardless of the base machine's Linux OS since I move between Fedora and Ubuntu machines. 

These were developed with the help of AI through back and forth chats and step by step testing, not agentically, so that I understand each line of the code.

I am by no means an expert at any of these, however many of these scripts are based on an original install script from the project and then modified to work with Distrobox.
